# ANT+ replaces BLE, and the firmware leaves Zephyr

The rear light is controlled from the rider's ANT+ bike computer through the ANT+ Bike Lights profile instead of BLE. The only ANT SoftDevice for the nRF52833 that fits is S212 (ANT only, 72 kB). The ANT SoftDevices are not supported by Zephyr or the nRF Connect SDK, so the firmware is bare metal on the SoftDevice: interrupts only post events, the main loop owns all state (as in the Zephyr firmware), and `sd_*` calls replace the Zephyr drivers where the SoftDevice owns a peripheral. We did not port to the nRF5 SDK because only the SoftDevice is needed from it and the SDK is end of life. There is no BLE any more: the BLE link from the front light (`software/front_light_central`) no longer controls the rear light and the Zephyr firmware (`../rear_light_peripheral`) is kept only as the reference for behaviour. A future front light becomes an ANT+ light itself. The alternative S340 (ANT and BLE together, 200 kB) would keep BLE but costs flash, RAM and radio time and was not wanted. Bench result (see VERIFY.md): a Wahoo ELEMNT BOLT v2 finds, reads and commands the prototype. The evaluation licence key of the SoftDevice is non-commercial, which matches the project's non-commercial clause; any other use needs its own ANT licence.
