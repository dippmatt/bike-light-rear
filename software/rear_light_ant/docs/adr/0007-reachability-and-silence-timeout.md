# Deep Sleep is unreachable, and controller silence never switches the light off

Two behaviours that the profile leaves to the product. First, Deep Sleep closes the ANT channel (the same rule as the BLE firmware): a bike computer cannot wake a sleeping light, only the button or USB power can. The state Off (set by a controller) keeps the channel open, so a light switched off from the bike computer can be switched on from it again. Second, the profile says a light returns to unconnected and switches its beam off when no controller message arrives for two minutes. This firmware does return to unconnected after that time (light index 0, so the next controller forms the network again), but it does not touch the beam: a rider whose bike computer is merely quiet or out of range must not suddenly lose the rear light. The Wahoo bench test showed a keep-alive message about every 24 s, so the timeout does not fire during normal use. Revisit if another controller does not send keep-alives.
