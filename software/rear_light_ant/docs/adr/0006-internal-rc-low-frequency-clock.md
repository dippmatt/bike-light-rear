# The low-frequency clock is the internal RC oscillator

The board has no 32.768 kHz crystal (XL1/XL2 are not connected), so the SoftDevice runs from the internal RC oscillator with calibration. The SoftDevice release notes state that this is not tested or intended for use with the ANT stack. We accept the risk because the bench prototype works with a Wahoo ELEMNT BOLT v2 on this clock (finding, reading, commands, reconnect), and a crystal would need a new board revision. An apparent clock error of +8.2 % in the first measurements came from the WSL host clock (about 9 % slow against NTP), not from the board (VERIFY.md). `make LFCLK=xtal` builds for a crystal and `LFCLK=synth` derives the clock from the 32 MHz crystal at the cost of current; both stay as build options. If a controller drops the link or the battery test shows a problem, the crystal revision is the fix.
